# 辩论赛场多主题配色系统（曜石黑橙、玄黑锦标金、电竞霓虹等）实施方案

针对线下大屏投影、转播直播及不同赛事规格（常规赛、决赛争冠、电竞思辨等），为辩论大屏计时系统打造**多套沉浸式专业色彩主题**，重点落地用户指定的**「曜石黑橙（Obsidian Ember Orange）」**，并在顶部导航栏与设置弹窗中提供即时热切换与本地持久化记忆。

---

### 用户确认与核心决策

> [!IMPORTANT]
> 根据用户的明确确认：
> - **管理与切换入口**：**顶部导航栏**新增快速主题切换器（支持直观色球指示），**系统设置弹窗**新增专门的主题视觉管理面板。
> - **主题色彩阵列**：涵盖**曜石黑橙**（核心重点）、**玄黑锦标金**（决赛荣誉）、**深蓝经典**（高校常规）、**赛博霓虹**（电竞思辨）、**极简纯黑**（OLED 超高对比度）。
> - **适配深度**：全站沉浸式换肤，包含背景深色渐变、大计时器荧光发光（Glow）、队伍边框色、按钮高亮、音效波纹及阴影氛围。

---

## 1. 概述与核心价值

- **核心价值**：
  - 传统辩论投影界面往往千篇一律，切换为黑橙、黑金或霓虹后，不仅现场视觉震撼力倍增，还能完美契合不同赛事品牌的主视觉（如世界杯橙、青年公开赛霓虹、冠军总决赛黑金）。
  - 纯黑与高饱和度强调色组合（黑底+亮橙 / 黑底+金耀），在剧场聚光灯与大型投影仪投射下具有极高的对比度（WCAG AAA 级），观众与评委百米外均能秒级看清时间。

1. **顶部导航一键切换**：
   - 顶部右侧新增「主题色」气泡按钮，显示当前主题的代表双色圆点（例如黑橙为 `⚫🟠`，黑金为 `⚫🟡`）。
   - 点击弹出轻量级下拉菜单，单次点击即刻无刷新应用全场。
2. **设置弹窗深度预览**：
   - 在「配置赛制」弹窗中新增「主题配色」选项卡，展示各主题的可视化卡片预览图，点击即可设为默认。
3. **本地状态持久化**：
   - 切换主题后自动保存至 `localStorage`（键名 `debate_stage_theme_v1`），刷新或重新进入时自动还原。

## 4. 技术架构与改动范围

### A. 主题配置模块 (`src/themes.ts`)
- 定义统一的 `ThemeConfig` 接口：
  - `id`: `ThemeId`
  - `name`: 中文名称
  - `description`: 适用场景简述
  - `previewColors`: [主背景色, 强调色]
  - `bgClass`: 页面背景渐变 Tailwind 类
  - `cardBgClass`: 计时器卡片背景与边框类
  - `accentColor`: 强调文字与按钮类
  - `glowClass`: 核心倒计时发光 CSS 类
  - `primaryBtnClass`: 主启动按钮背景与发光阴影类
- 集中导出 5 套精细调配的主题参数。

### B. 核心状态与主屏适配 (`App.tsx`)
- 新增 `currentThemeId` 状态与持久化读取/写入。
- 顶部导航栏挂载快捷切换浮层（`ThemeSwitcher`）。
- 将主题上下文参数动态传递给舞台背景、辩题条、操作按钮以及双对抗卡片。

### C. 计时器卡片适配 (`TimerBox.tsx`)
- 动态套用主题的倒计时高亮、外发光（`glow-orange` / `glow-gold` / `glow-cyan` / `glow-red` 等）与主发言按钮样式。

### D. 设置弹窗拓展 (`ConfigModal.tsx`)
- 在「音效与操作偏好」或单独标签中加入主题卡片选择器，支持实时试色。
